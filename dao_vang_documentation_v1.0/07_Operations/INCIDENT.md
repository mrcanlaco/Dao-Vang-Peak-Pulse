# INCIDENT MANAGEMENT

Mức độ:

- SEV1: corruption/raw loss/leakage ảnh hưởng kết luận.
- SEV2: collector ngừng dài, schema drift.
- SEV3: report/CLI lỗi không mất dữ liệu.

Incident record:

- timeline;
- impact;
- root cause;
- containment;
- fix;
- affected versions;
- regression tests;
- follow-up.
