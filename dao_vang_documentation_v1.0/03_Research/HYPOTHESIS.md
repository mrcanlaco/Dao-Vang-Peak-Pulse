# HYPOTHESIS REGISTRY

## Template

```yaml
hypothesis_id: HYP-001
statement: ...
behavioral_rationale: ...

expected_direction: ...

```

## Lifecycle

Hypothesis → Experimental → Validated → Production → Retired

## Quy tắc

- Không xóa giả thuyết thất bại.
- Không đổi statement cũ; tạo revision.
- Mỗi experiment phải trỏ hypothesis.
- Promotion cần evidence ngoài mẫu.
- Retirement phải có lý do.
