# ĐẢO VÀNG DOCUMENTATION v1.0

Bộ tài liệu nguồn chân lý cho quá trình nghiên cứu, phát triển và kiểm chứng Đảo Vàng.

## Mục đích

- Giữ toàn bộ dự án bám sát Hiến pháp.
- Cho phép Codex và các agent làm việc mà không phải tự đoán nghiệp vụ.
- Chuẩn hóa dữ liệu point-in-time, label, feature, validation và versioning.
- Giảm scope creep, data leakage và nợ kỹ thuật.
- Hỗ trợ một người vận hành dự án trong dài hạn.

## Thứ tự ưu tiên

1. `00_Governance/CONSTITUTION.md`
2. `01_Product/MVP_SCOPE.md`
3. Specification chuyên ngành
4. `04_Engineering/ARCHITECTURE.md`
5. `05_AI/AGENTS.md`
6. Task/Work Board hiện hành
7. Code

## Cấu trúc

- `00_Governance`: quyền hạn, tầm nhìn, nguyên tắc, roadmap.
- `01_Product`: phạm vi, người dùng, thành công, non-goals.
- `02_Data`: nguồn, schema, quality, alignment, storage.
- `03_Research`: label, feature, baseline, validation, leakage.
- `04_Engineering`: kiến trúc, coding, testing, dependency.
- `05_AI`: quy tắc Codex, review, multi-agent, prompt.
- `06_Development`: setup, branch, CI, release.
- `07_Operations`: backup, observability, incident, security.
- `08_Reference`: Binance, repo tham khảo, ADR.
- `contracts`: hợp đồng module.
- `playbooks`: quy trình thao tác chuẩn.
- `examples`: ví dụ input/output/config.
- `docs_active`: work board và session log.

## Trạng thái

Documentation v1.0 là baseline để bắt đầu Phase 2: dựng repository foundation và collector.
