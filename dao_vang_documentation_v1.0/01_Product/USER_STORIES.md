# USER STORIES

## Chủ dự án / Researcher

- Tôi muốn tải dữ liệu BTCUSDT có version để có thể tái tạo experiment.
- Tôi muốn biết nguồn nào thiếu hoặc trễ trước khi tin feature.
- Tôi muốn thay Label Version mà không làm mất kết quả cũ.
- Tôi muốn chạy baseline và walk-forward bằng config.
- Tôi muốn xem false positive và regime breakdown.
- Tôi muốn biết experiment dùng code commit, dataset và feature version nào.

## Codex / Agent

- Tôi muốn có scope, contract, gate và acceptance rõ.
- Tôi muốn biết file nào được phép sửa.
- Tôi muốn có schema và examples để không tự đoán.
- Tôi muốn test leakage cụ thể.
- Tôi muốn dừng khi semantic chưa được quyết định.

## Người dùng watchlist tương lai

- Tôi muốn biết coin nào đáng theo dõi.
- Tôi muốn probability, evidence quality, expected window và invalidation.
- Tôi không muốn hệ thống giả vờ chắc chắn.
