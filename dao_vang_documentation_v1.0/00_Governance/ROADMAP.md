# ROADMAP

## Phase 1 — Documentation v1.0
- Chuẩn hóa governance, data, research, engineering và AI workflow.
- Đầu ra: bộ tài liệu nguồn chân lý.

## Phase 2 — Repository Foundation
- Python project, quality gates, config, logging, CI.
- Đầu ra: repo chạy test sạch.

## Phase 3 — Data MVP
- OHLCV, funding, OI, taker, ratios.
- Raw, normalized, quality, alignment.
- Đầu ra: dataset point-in-time có manifest.

## Phase 4 — Research MVP
- Label v0.1, feature v0.1, baselines, walk-forward.
- Đầu ra: experiment report và kết luận edge.

## Phase 5 — Forward Collection
- Collector chạy định kỳ, snapshot liên tục.
- Đầu ra: dữ liệu mới phục vụ forward test.

## Phase 6 — Watchlist
- Chỉ sau khi có evidence ngoài mẫu.
- Không auto trade.

## Gate chuyển phase
Mỗi phase chỉ được chuyển khi acceptance criteria và tài liệu liên quan được cập nhật.
