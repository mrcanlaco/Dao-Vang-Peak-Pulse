# SETUP

## Yêu cầu

- Git
- Python 3.12
- uv

## Khởi tạo dự kiến

```bash
uv sync
uv run pre-commit install
uv run pytest
```

## Environment

- UTC.
- Public Binance endpoints.
- Data directory cấu hình qua `.env` hoặc config.
- Không cần API trade key.

Chi tiết command được cập nhật khi Phase 2 tạo repo code.
