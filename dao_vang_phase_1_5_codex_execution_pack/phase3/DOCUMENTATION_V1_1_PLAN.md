# PHASE 3 — DOCUMENTATION v1.1

## Trigger

Chỉ bắt đầu sau khi MVP RC chạy end-to-end.

## Audit

So sánh:

- tài liệu vs code;
- schema spec vs actual models;
- endpoint assumptions vs contract tests;
- time alignment vs implementation;
- label spec vs tests;
- architecture vs imports;
- dependencies approved vs installed;
- commands documented vs CLI;
- operational assumptions vs runtime.

## Output

- Documentation v1.1.
- ADR mới.
- Deprecated decisions.
- Known limitations.
- Updated examples.
- Updated AGENTS/task rules.
- Changelog từ v1.0 → v1.1.

## Không làm

Không sửa tài liệu để che code sai. Nếu code trái Constitution/spec, ưu tiên sửa code hoặc ghi decision explicit.
