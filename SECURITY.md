# Security Policy

## Supported Versions

We actively provide security updates for the current main branch and latest releases.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :white_check_mark: |

---

## Reporting a Vulnerability

The DAO VANG team takes the security of our quantitative software and user data very seriously.

If you discover a security vulnerability, **please DO NOT report it as a public GitHub issue**.

Instead, please report security issues responsibly through one of the following channels:
1. **GitHub Private Vulnerability Reporting:** Open a private advisory on this repository under the **Security** tab.
2. **Email:** Reach out to the maintainers directly via repository contact email.

### What to Include in Your Report
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Impact assessment (e.g. data leak, denial of service, API abuse).
- Any suggested mitigations or fixes.

### Response Timeline
- We will acknowledge receipt of your report within **48 hours**.
- We will provide a status update and estimated remediation schedule within **5 business days**.
- Once a fix is validated and released, we will publish an advisory and credit the reporter (if desired).

Thank you for helping keep DAO VANG and its users secure! 🛡
