# Đảo Vàng PeakPulse 2.0.0-rc.2

Release date: 2026-08-27
Release status: release candidate; shadow-only until calibration and shadow gates pass.

## Runtime contract

| Field | Value |
| --- | --- |
| Active frozen model | `frozen_20260811_082824_96df7ec9` |
| Dataset / label | `distribution_short_v1` |
| Forward horizon | 24 hours / 1,440 minutes |
| Serving features | 25, ordered and required; missing values are rejected |
| High-confidence threshold | 0.60 |
| Watch threshold | 0.45 |
| Calibration | `identity_v1` is not considered production-valid |
| Operating mode | Shadow |

The runtime now refuses to produce an alertable calibrated score when a frozen
bundle declares `identity_v1`. This keeps the current bundle available for
diagnostics and shadow collection while preventing raw model probabilities from
being presented as calibrated trading evidence.

## Operational changes

- Dashboard authentication uses a short-lived signed `HttpOnly` session cookie.
- CORS is disabled by default and can be enabled only for explicitly configured origins.
- Direct Git-based updating is disabled by default; deployments should use a reviewed release pipeline.
- Failed pulls no longer recover by overwriting the working tree with `git reset --hard`.
- Frontend CI uses `npm ci` against the committed lockfile.

## Promotion checklist

Before promoting this release candidate to production, attach a fitted and
checked calibration artifact, verify the active model checksum, and pass the
shadow evaluation gates in `docs/KE_HOACH_NANG_CAP_DU_BAO_SOM.md`.
